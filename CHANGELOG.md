## 0.1.0

* **中文：** 首发：数字 HUD（`techNeon` / `hud` / `performance` / `pulseBreath`）与科技风模拟集群（`classic` 宝马双圆、`racing` 法拉利主转速表）。  
  **English:** Initial release: digital HUD styles (`techNeon` / `hud` / `performance` / `pulseBreath`) and tech analog clusters (`classic` BMW dual gauges, `racing` Ferrari-style tach).
* **中文：** 天气层：内嵌改编 flutter_weather_bg（MIT），支持晴雨雪雾霾等 `WeatherType`。  
  **English:** Weather layer: vendored flutter_weather_bg (MIT) with sunny / rain / snow / fog / haze `WeatherType`s.
* **中文：** 粒子层：`windRush`、`blackHole`、`starTunnel`、`roadTrack`、`ionStorm`；流速随车速惯性变化；`roadTrack` 地平线以上透明以透出天气。  
  **English:** Particle layer: `windRush`, `blackHole`, `starTunnel`, `roadTrack`, `ionStorm`; inertial speed-linked flow; `roadTrack` keeps sky transparent over weather.
* **中文：** `DriveSimulation`：PRND 互锁、空档只拉转速、倒车限速；示例支持按住加速、方向键与档位条。  
  **English:** `DriveSimulation`: PRND interlocks, neutral rev-only, reverse speed cap; example supports hold-to-accel, arrow keys, and gear strip.
* **中文：** 示例控制面板：主题 / 天气 / 粒子 / 车型 / 彩虹速度；面板关闭手势修复。  
  **English:** Example control panel: theme / weather / particles / vehicle / rainbow speed; panel dismiss gesture fixed.
